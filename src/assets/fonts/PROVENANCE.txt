Web fonts of khaylub.com (the design initiative's F3 package, 2026-09-20). Both faces are under the
SIL Open Font License 1.1; the licence texts sit beside the files. Built once, locally, with
fontTools 4.57.0 (Python 3.13.1) from the official upstream release files; the commands are in
docs/RUNBOOK.md section 10.12; the input and output SHA-256 hashes below are the record.

Each face ships as one variable file (wght 400 to 700) split in two by character range: the core
(U+0020-007E, U+00A0, U+00A9, U+00B7, U+00D7, U+00C9, U+00E9, U+2013, U+2018-201D, U+2022, U+2026,
U+203A: ASCII plus the characters the site's text uses) on every page, and the extension (the rest of
Latin-1 Supplement, General Punctuation U+2010-205E, arrows U+2190-2199) only where a page uses one of
its characters. Layout features kept: kern, liga, calt, ccmp, mark, mkmk.
