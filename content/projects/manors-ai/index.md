## Status

Private beta. Nothing about this project runs on a public domain today, and its repository is private. This page exists so the project has an honest place on the site, not to show a product.

## The one rule

Never invent a number. Every figure in an estimate traces to a source with a date and a confidence level, so a contractor can defend the bid line by line.

## What can be said publicly

The tool is an estimating engine with a web interface, built by the owner with AI assistance in the code. Customer data, price sources, provider details, and internal screens are not published here and will not be.
