## Question

How have two spellings of one name, Marc and Mark, changed in U.S. male births since 1880?

## Data

Public Social Security Administration baby-name data covering 146 years, 1880 to 2025, downloaded by the notebook itself.

## Method

A public path in Python and Jupyter that anyone can re-run without a database, plus the original SQL Server integration kept as working evidence of database connectivity, with credentials handled through environment variables and never committed.

## Result

The chart of Marc versus Mark by year, generated by the public notebook, is in the repository. The key finding is stated in the README with the caveats that go with it.

## Repository

Code, the chart, and the run-it-yourself instructions are linked at the top of this page. The rendered notebook is embedded here at Phase 11.
